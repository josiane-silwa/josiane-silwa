##  About me
Sou Josiane da Silva, graduada em Tecnologia da Informação desde 2011. Possuo experiência em desenvolvimento web Frontend utilizando HTML5, CSS, JavaScript, React.js, Material UI, consumo de APIs REST. Experiência em desenvolvimento web Backend utilizando SQL, MySQL, PostgreSQL, Python, Django, Django Rest Framework e desenvolvimento de APIs. Experiência em manipulação, processamento e análise de dados utilizando shell script, Python e softwares de visualização de dados. Possui conhecimento em Git, Github e Docker. Gosto de estudar e estou sempre buscando novos conhecimentos.
